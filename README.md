A Wi-Fi network name that tells a whole story in 32 characters: "My WiFi Has a Restraining Order" — a network so plagued by freeloaders it needed a legal restraining order.

## Run it

```sh
python3 main.py
```

It writes the entry (31 characters) to `/output/entry.txt` and prints the entry with its character count. Deterministic, no network, no randomness.
